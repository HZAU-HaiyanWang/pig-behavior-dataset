# Pig Behavior Dataset

> **Release status:** This repository is being prepared for the public release of an annotated pig-behaviour dataset. It currently contains documentation and reproducibility materials only. The immutable **v1.0.0** data archive, licence, and DOI will be added after final data verification and rights confirmation.

## Overview

This project will provide an annotated video dataset for individual tracking and multi-behaviour recognition of group-housed pigs. It is intended to support reproducible research in precision livestock farming, computer vision, and animal-behaviour analysis.

## Planned public release

The public release will contain:

- video data and/or clearly documented video-derived files;
- individual tracking annotations;
- multi-behaviour detection annotations;
- exact train/validation/test split manifests;
- annotation-format specifications, sequence metadata, and file checksums;
- a versioned Zenodo archive with a persistent DOI.

The dataset files themselves will be archived through Zenodo rather than stored directly in this GitHub repository. This keeps the data release versioned, citable, and independently downloadable.
