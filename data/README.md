# Data archive policy

Raw videos, image sequences, large annotation packages, and model files must **not** be used as the primary dataset archive in this GitHub repository.

Before public release, package the final verified dataset as a versioned Zenodo **Dataset** record. The Zenodo record must include the actual release files, this documentation, the licence, split manifests, and a checksum manifest.

After publication, replace the placeholders below:

- **Zenodo record:** [URL]
- **Version-specific DOI:** [DOI]
- **Archive version:** [v1.0.0]
- **Licence:** [licence]

A small, non-sensitive example may later be placed in this repository for format illustration, provided it is also covered by the declared licence.
